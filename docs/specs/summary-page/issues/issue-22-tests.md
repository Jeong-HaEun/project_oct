# 이슈 22 · 시험 문제 (매체별 BEST 소재 5)

- 이슈: GitHub #22 「요약 페이지: 매체별 BEST 소재 5」
- 근거: [prd.md](../prd.md) 4장 (하위 5 · 전환 0 경고만 캠페인 페이지), [metrics.md](../../../metrics.md) 인사이트 규칙 (광고비 10만 원 이상 + 전환 1건 이상), 합계 규칙 (합계끼리 나눈다)
- 다음 단계: `/tdd-red 22` 가 이 파일을 읽어 테스트 코드를 만든다.

## 1. 함수 모양

| 파일                   | 함수                | 받는 값            | 돌려주는 값                                                                        | 한 줄 설명                                                                  |
| ---------------------- | ------------------- | ------------------ | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `src/utils/metrics.js` | `rankBestCreatives` | `rows, latestDate` | 최대 5개 `[{ campaignName, adGroupName, creativeName, cost, revenue, roas, cpa }]` | 최근 7일 줄을 소재별로 합친 뒤, 조건에 맞는 소재를 ROAS 높은 순으로 5개까지 |

다시 쓰는 기존 함수: `getWeekRanges` · `filterByDateRange` (`dates.js`), `sumTotals` · `calcRoas` · `calcCpa` (`metrics.js`), `formatWon` · `formatPercent` (`format.js`, 화면 표시).

### 값 약속 (결정)

- **결정 1:** "같은 소재" = 캠페인 + 광고그룹 + 소재 이름이 모두 같은 줄. 이름이 같아도 광고그룹이 다르면 다른 소재로 따로 센다.
- **결정 2:** ROAS 가 같으면 매출이 큰 소재가 먼저.
- **결정 3:** 기준일은 전체 데이터의 최근 날짜, 함수는 매체 필터를 거친 줄을 받는다 (이슈 #2 결정 A, 합계 카드와 같음). 최근 7일 = `getWeekRanges(latestDate).current`.
- 순위 조건: 7일 **합계** 광고비 ≥ 100,000 **그리고** 합계 구매(`conversions`) ≥ 1. 각 날이 아니라 합친 값으로 판단한다.
- `roas` 는 퍼센트 숫자(400 = 400%), `cpa` 는 원. 반올림은 표시 함수가 한다.
- [전체] 일 때의 안내 문구, 빈 목록 문구는 화면(컴포넌트)이 정한다.
  - 빈 목록: "조건에 맞는 소재가 없어요 (광고비 10만 원 이상 · 구매 1건 이상)"
  - [전체]: "매체를 고르면 BEST 소재를 볼 수 있어요"
