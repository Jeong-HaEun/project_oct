# 디자인 규칙 따르기

화면이나 스타일을 건드리기 **전에** 아래 순서를 지킨다.

1. `docs/design/design.md` 를 끝까지 읽는다. (색 이름은 `src/index.css` 의 `@theme` 에 있다)
2. 만들 부품이 design.md 5절(부품)에 있으면 **적힌 클래스를 그대로** 쓴다. 비슷한 걸 새로 만들지 않는다.
   - 버튼 → 5-3, 매체 필터 → 5-4, 전주 대비 배지 → 5-5, 표 → 5-7, 그래프 → 5-8
3. 상태가 있는 부품은 6절과 5절의 상태 규칙(기본·마우스 올림·눌림·키보드 선택·비활성·처리 중, 불러오는 중·오류·빈 상태)을 **빠짐없이** 넣는다.
4. 배치는 모바일 먼저: 기본 클래스는 휴대폰, `md:` 부터 데스크톱 (7절).
5. 8절 **금지 목록**을 어기지 않는다.
   - 임의 색 `bg-[#...]`, 기본 팔레트 `bg-red-500` · `text-gray-600`, `.jsx` 안의 `#색코드`, 카드 `shadow-*`
   - 그래프처럼 클래스를 못 쓰는 곳은 `var(--color-primary)` 같은 CSS 변수를 쓴다.
6. design.md 에 없는 색·부품이 꼭 필요하면 **멋대로 만들지 말고** 사용자에게 먼저 묻는다.
   - 승인되면 `src/index.css` 의 `@theme` 과 design.md 표를 함께 고친다. 새 글자색은 대비 4.5:1 이상인지 계산해서 표에 적는다.
7. 작업이 끝나면 사용자에게 "design.md 의 어느 절을 따랐는지" 한 줄로 알려준다.

## 참고

- 파일을 고친 직후 훅(`.claude/hooks/`)이 8절 금지 목록을 자동 검사한다. 경고가 나오면 고치고 다시 확인한다.
- 계산은 컴포넌트에 쓰지 않고 `src/utils/metrics.js` 를 쓴다 (CLAUDE.md 규칙).
